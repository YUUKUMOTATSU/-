# 十月怀胎模拟器

一个单文件网页：拖动时间轴，查看胎儿从末次月经第 1 天到第 280 天（预产期）的发育变化。

- **动画画面**：卵子 → 受精 → 细胞分裂 → 囊胚 → 着床 → 胚胎（C 形身体、心跳、肢芽）→ 胎儿（长大、长肉、长头发、转为头朝下），带胎盘、脐带、比例尺和胎心。
- **每周说明**：宝宝这一周在发育什么、身长体重、大小相当于什么水果。
- **器官进度**：心脏、大脑、眼睛、耳朵、四肢、肺、肾脏、消化系统、骨骼、皮肤、生殖器官。
- **妈妈需要注意**：每周注意事项、宫底高度、参考增重、子宫大小侧影、产检时间表和需要立即就医的情况。
- **控制**：播放 / 暂停、三档速度、±1 天 / ±1 周、关键节点快速跳转，输入末次月经日期可直接定位到今天。

直接用浏览器打开 `index.html` 即可使用，不需要安装任何依赖。

> 画面为示意，尺寸体重为常见参考值。本页仅作科普，不能替代医生的检查和建议。
