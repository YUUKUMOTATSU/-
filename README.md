# 高洲新家布局

UR 高洲第一 3-3-5-203（3DK · 54㎡）的户型布局工具。户型按 UR 平面图上标注的尺寸（毫米，墙中线）建模。

`index.html` 是页面源码，按 Claude Artifact 的格式写（不含 `<!doctype>` / `<head>`），发布后在浏览器里用。

功能：

- 按真实比例画出户型：墙、门窗、开门范围、榻榻米，以及和原图一致的尺寸线
- 从家具库拖入或点击添加家具，可以移动、旋转（15° 吸附）、拖角点改尺寸，也能直接输入实际尺寸（cm）
- 选中家具时显示到四周墙面或家具的净距离；穿墙、重叠会标红，挡门会标橙
- 2D / 3D 切换（3D 用 three.js r128）
- 撤销 / 重做、保存多个方案、导出 PNG

门窗位置、浴室和洗面所之间的分隔等细节是按图纸比例估的，误差约 ±10–15 cm，以现场实测为准。
