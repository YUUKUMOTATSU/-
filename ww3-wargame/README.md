# 台海三战兵棋推演

以台海战争为导火索的第三次世界大战假想兵棋推演。单个 HTML 文件，用浏览器直接打开 `index.html` 即可（字体从 Google Fonts 加载，离线时会退回系统字体）。

## 页面内容

- **实力天平**：轴心国阵营（中、俄、朝、伊、白俄）与同盟国阵营（美、日、台、韩、北约、澳、菲）的军费、GDP、人口、兵力、核弹头、航母、核潜艇、五代机、制造业与造船产能对比，以及分国家数据表。
- **战局沙盘**：六个阶段（危机升级 → 首轮打击 → 登陆战 → 战火蔓延 → 封锁与消耗 → 核门槛），地图自动切换战区并标出打击、登陆、封锁和战线，可自动播放。
- **推演台**：可调参数的蒙特卡洛模型（每次 2,000 局），参数包括台湾抵抗意志、美国介入时机、日本基地、远程反舰导弹库存、民船征用、核克制程度、多战区外溢、是否打击大陆本土。输出结局分布、常规战代价和单局回放曲线。
- **结论与来源**：结论中的百分比由模型实时计算。

## 模型说明

以天为回合、最长 60 天，模拟渡海运力、盟军拦截率、岛上地面战（简化兰彻斯特方程）与核门槛。每局随机抽取双方实战效能和开局打击效果。损失量级按 CSIS 2023 年《The First Battle of the Next War》基准情景校准。这是用于比较不同条件相对影响的教学模型，不是预测。

## 数据来源

SIPRI 军费数据库（2024 年数据）、IISS《Military Balance 2025》、FAS《Status of World Nuclear Forces 2025》、CSIS 兵推报告（2023）、彭博经济研究（2024）、IMF《世界经济展望》2025、美国国防部《中国军事与安全发展报告》2024、Xia 等《Nature Food》2022。

地图数据：[world-atlas](https://github.com/topojson/world-atlas)（Natural Earth），已预先投影为 SVG 路径内嵌在页面中。
